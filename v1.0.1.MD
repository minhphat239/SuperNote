# SuperNote — Student Reminder App
### Product & Feature Plan

---

## 1. Vision & Positioning

**One-line pitch:** SuperNote is a reminder app built *specifically for students*, where you can add a reminder just by typing (or speaking) naturally — "Math homework due Friday 5pm, repeat every week" — and it understands you.

**Why it stands out from generic reminder apps (Google Keep, Todoist, Microsoft To Do, Apple Reminders):**
- Most reminder apps are generic — built for grocery lists and work tasks, not academic life (classes, assignments, exams, study sessions).
- SuperNote's core differentiator is **Natural Language Processing (NLP) input** tuned for student vocabulary ("quiz," "assignment," "lecture," "submit," "deadline," "exam week").
- A home-screen **widget** keeps today's/this week's academic tasks visible without opening the app.
- **Repeated reminders** are built around class schedules (weekly lectures, biweekly labs) rather than generic daily/weekly repeats only.

Since you want to start with **limited functions** (an MVP), the plan below separates **Core MVP features** from **Future/Phase 2 features**, so you don't overbuild on day one.

## 2. Core MVP Features (Build These First)

| # | Feature | Description |
|---|---------|-------------|

## 2A. Auto-Update

"Auto-update" can mean two different things — worth building both, since together they're a nice differentiator:

**A. App auto-update (keeps the app itself current)**
- The app silently checks for a new version on launch (or in the background) and either updates itself automatically or prompts "Update available — install now?"
- On Android this is usually handled by the Play Store's in-app update API (`Immediate` or `Flexible` update flow) — you don't need to build this from scratch, just wire it up.
- On iOS, Apple doesn't allow silent self-updates; the best you can do is check the App Store version and show a friendly "New version available" banner.
- For a smaller/limited release outside the store (e.g., sideloaded APK for a school), you can build a simple version-check: app pings a small JSON file/endpoint with the latest version number and download link, and prompts the user if it's out of date.

**B. Smart auto-updating reminders (the more unique idea)**
This is where it gets useful for students specifically:
- **Auto-reschedule overdue tasks** — if a reminder is missed, instead of just sitting as "overdue" forever, SuperNote automatically proposes a new time ("You missed this — move to tomorrow same time?").
- **Auto-adjust for semester changes** — if a class's repeat reminder was set for the whole semester and the student later shifts one class time, offer to auto-update all future occurrences at once (like "edit this event or all future events" in calendar apps).
- **Auto-sync repeat drift** — if a repeated reminder is manually snoozed a few times in a row, the app can suggest "This always gets snoozed — want to permanently move it to a later time?"

## 3. NLP Quick-Add — How It Should Work

This is your app's signature feature, so it deserves a clear design.

**Input example → Parsed result:**

| User types | Extracted |
|---|---|
| "Submit math homework tomorrow 6pm" | Title: Submit math homework · Date: tomorrow · Time: 18:00 |
| "Chemistry lab every Tuesday 9am" | Title: Chemistry lab · Repeat: Weekly (Tue) · Time: 09:00 |
| "Study for final exam next Friday" | Title: Study for final exam · Date: next Friday · Time: (default/none) |
| "Remind me every day at 8am to check email" | Title: Check email · Repeat: Daily · Time: 08:00 |

**Recommended approach (keep it lightweight for MVP):**
1. Use a **rule-based / regex + dictionary parser** first (fast, offline, free, no API cost) — this is enough for 80% of student phrasing patterns (dates, times, "every", "next", weekday names).
2. Only if rule-based parsing proves insufficient, layer in a small on-device NLP model or a cloud NLP API (e.g., date/time entity extraction libraries like `sutime`, `duckling`, or `chrono-node` for JS) — these are purpose-built for date/time parsing and are much cheaper/faster than a full LLM call for this narrow task.
3. Reserve a full LLM-based parser (like the Anthropic API) for Phase 2, when you want more flexible, conversational input ("remind me a bit before my chem lab starts, it's usually around 9").

**Fallback UX:** If parsing confidence is low, show an editable confirmation card ("Did you mean: Chemistry lab, Tuesdays, 9:00 AM?") rather than silently guessing wrong.

## 4. Notifications

- **Local notifications** (no server needed) triggered by the OS's scheduling APIs — reliable and battery-friendly.
- Notification content: task title + category icon + quick actions ("Done," "Snooze").
- Pre-reminder option: notify X minutes/hours before (configurable per reminder or as a global default).
- Respect **Do Not Disturb** and quiet hours (e.g., no notifications after 11pm unless the reminder is time-critical).

---

## 5. Repeated Reminders

Recommended repeat types for MVP:
- Every day
- Every week (choose one or more weekdays — e.g., Mon/Wed/Fri for classes)
- Every X weeks (for biweekly labs)
- Custom end date ("repeat until end of semester" — lets a student set a semester end date once)

---

## 6. Widget Design

- **Small widget:** Next 1 reminder (title + time).
- **Medium widget:** Next 3–5 reminders as a compact list.
- Tap behavior: tapping a reminder opens the app to that item; a checkbox/tap-to-complete directly on the widget is a nice-to-have if the platform supports interactive widgets.
- Auto-refreshes when a reminder is added, completed, or its time passes.

## 8. Suggested Tech Stack (starting point)

- **Mobile app:** Flutter (one codebase, easier to later expand to both Android & iOS) or native Android (Kotlin) if you want to launch fastest on one platform.
- **Local storage:** SQLite (via `sqflite` in Flutter, or Room in native Android) — no backend needed for MVP.
- **Notifications:** Platform-native local notification APIs (`flutter_local_notifications`, or `AlarmManager`/`WorkManager` on Android).
- **Widget:** Android App Widgets (native) or Flutter's home-widget plugin.
- **NLP/date parsing:** `chrono-node`-style date parser ported to Dart, or a small custom regex parser.

## 8A. UI Design — Screens & Buttons

Here's a screen-by-screen breakdown so a designer/developer can start building a clean, modern UI.

**Design direction:** soft rounded cards, one clear accent color per category (e.g., blue = Class, red = Exam, orange = Assignment, green = Personal), generous white space, large legible type — avoid cramming too much per screen.

### 1. Top App Bar (always visible)
- Sits fixed at the very top of every main screen, in the app's primary accent color
- **Left:** app logo/wordmark ("SuperNote")
- **Right:** two small icon buttons — Calendar view shortcut, and Settings
- Purpose: gives constant, one-tap access to the calendar and settings without digging through menus, and visually anchors the brand color at the top of every screen

### 2. Home / Reminder List Screen
- **Below the top bar:** the NLP Quick-Add strip (see below) — pinned near the top of the Home screen itself, not hidden behind a button, so adding a task is the very first thing a user can do on opening the app
- **Grouped sections:** "Today," "Tomorrow," "This Week," "Later" — each collapsible
- **Reminder card (per item):** category color dot, title, time, small repeat icon if recurring
- **Buttons on each card:**
  - ✅ Checkmark (left) — mark complete
  - ⏰ Snooze icon (swipe or long-press) — opens quick snooze menu (10 min / 1 hr / tomorrow)
  - 🗑 Delete (swipe left)
- **Floating Action Button (FAB):** big "+" button, bottom-right — jumps back up and focuses the Quick-Add strip (useful once the user has scrolled down the list)
- **Bottom navigation bar:** Home | Calendar view | Statistics | Settings (4 icons)

### 3. NLP Quick-Add — Made Easy
This is pinned directly under the top bar on the Home screen, not a separate screen, so adding a task takes the fewest taps possible:
- **One text field** with placeholder example text (e.g., *"Math homework tomorrow 6pm"*) so users immediately understand the format without instructions
- **Microphone button** inside the field for voice input, for when typing is inconvenient (walking between classes)
- **Live preview chips** appear *as the user types* — Title, Date, Time, Repeat, and a colored Category chip — so they can visually confirm what the app understood before saving, catching any misread date/time immediately
- **A single "Save reminder" button** appears once the preview is showing — one tap to confirm and add it to the list below, no extra screens or forms needed for the common case
- If a user wants to fine-tune something (e.g., add notes, change category manually), an "Edit details" link expands into the full manual fields — but this stays optional, not required

### 4. Reminder Detail / Edit Screen
- Title field, notes field (optional), category selector (colored chips: Class/Exam/Assignment/Personal)
- Date & time pickers
- Repeat selector (None / Daily / Weekly + day chips / Custom)
- Pre-reminder offset dropdown ("Notify me: at time of event / 30 min before / 1 hr before / 1 day before")
- **Buttons:** "Save" (primary, full-width), "Delete Reminder" (text button, red, bottom)

### 5. Calendar View Screen
- Month grid at top, days with reminders show a small colored dot matching category
- Tap a day → list of that day's reminders appears below the calendar
- Small "+" button (top-right) to add a reminder for the selected day

### 6. Statistics Screen (Phase 3)
- Simple weekly bar chart: tasks completed vs. missed
- Procrastination score shown as a friendly badge/ring (not harsh — framed positively, e.g., "On track" / "Catching up")
- Category breakdown (pie or horizontal bars: how many reminders per category)

### 7. Settings Screen
- Toggle: Dark mode
- Toggle: Notification sound / vibration
- Default pre-reminder offset
- Widget style preference (compact / detailed)
- "Check for updates" button (ties into the auto-update feature)
- About / Version number at the bottom

### 8. Widget (Home Screen)
- **Small widget:** category color strip on the left edge, task title, time — tap opens the app directly to that reminder
- **Medium widget:** stacked list of 3–5 upcoming reminders, each with a small checkbox users can tap to mark done directly from the widget (no need to open the app)
- **Header row on widget:** small "+" icon to jump straight to Quick-Add without opening the full app

### Suggested color & style system
| Element | Style |
|---|---|
| Primary accent | One brand color (e.g., a calm indigo or teal) for buttons/FAB |
| Category colors | Class = blue, Exam = red, Assignment = orange, Personal = green |
| Corners | Rounded cards (12–16px radius) for a soft, modern feel |
| Typography | One clean sans-serif (e.g., Inter, Poppins), bold for titles, regular for details |
| Dark mode | Supported from day one — students use phones at night before deadlines |

## 8B. Redesign Notes — Based on Current Build

Looking at the current build (Notes screen with the update banner, note cards, and bottom nav), a few concrete fixes will make it feel more intentional and less generic:

**What's making it feel flat/plain right now:**
- Top bar has 3 elements (edit icon, search, refresh) with no clear priority — nothing tells the eye where to go first
- The "New version available" banner sits right at the top, competing with the actual content for attention every time the app opens
- Note cards are just title + timestamp with a lot of empty space — no color, no category distinction, no visual rhythm
- There's no way to add something quickly without hitting the "+" button first — the FAB alone makes "quick add" not actually quick

**The fix — a fixed Quick-Add Bar, always visible:**
- Place it **directly under the top bar**, above the note/task list — not hidden behind the "+" — so it's the first thing visible and usable the instant the screen opens
- Structure: a single rounded input field taking most of the width, placeholder text like *"Add a task... e.g. Math homework tomorrow 6pm"*, with a small circular **send/add icon button** on the right edge of the field itself (replaces needing to reach for the FAB for the common case)
- Typing and hitting the send icon (or Enter) parses it with NLP and adds it straight to the list below — no extra screen, no extra tap
- Keep the FAB, but repurpose it as a shortcut to the **full add screen** (for when someone wants to set notes, exact category, or a longer repeat rule) rather than the primary way to add something
- Move the "New version available" banner **out of the default view** — either collapse it into a small dot/badge on the Settings icon, or only show it as a slim one-line strip the user can swipe away, so it doesn't visually compete with the quick-add bar for top-of-screen attention
- Give each card a small **left-edge color strip or dot** matching its category (Class/Exam/Assignment/Personal) — this alone breaks up the "all white cards" flatness and adds instant visual scanning
- Slightly mute the timestamp text (lighter grey, smaller size) so it's secondary to the title, not equal weight with it

**Priority order for screen elements, top to bottom:**
1. Top bar (brand + 1–2 essential icons max)
2. Quick-Add Bar (always visible, always usable)
3. Note/task list (with category color accents)
4. FAB (secondary/advanced add)

## 9. Unique/Signature Features — Things Most Reminder Apps Don't Have

Since you specifically want features that set SuperNote apart, here are ideas that go beyond what Google Keep, Todoist, or Apple Reminders offer — organized so you can pick a few standout ones rather than build everything:

| Feature | What it does | Why it's different |
|---|---|---|
| **Timetable photo scan** | Student takes a photo of their printed/whiteboard class schedule; the app OCR-scans it and auto-creates repeated reminders for each class. | No mainstream reminder app auto-builds a whole semester schedule from a photo. |
| **Procrastination score** | Tracks how often a task is snoozed/rescheduled vs. done on time and shows a simple weekly score, not to shame but to nudge awareness. | Turns your own reminder data into self-insight, not just a to-do list. |
| **Study Focus Mode** | When a "study session" reminder starts, the app can (optionally) trigger the phone's Do Not Disturb + show a Pomodoro-style timer tied to that specific reminder. | Merges reminders + focus timer, which are usually separate apps. |
| **Deadline countdown widget** | Widget shows a live countdown ("Exam in 2d 4h") with color that shifts from green → yellow → red as it approaches, instead of a static list. | More visually urgent/at-a-glance than typical list widgets. |
| **Location-based nudge** | Optional: remind "Return library book" only when GPS detects you're near the library/campus, not just at a fixed time. | Combines time-based and location-based reminders, most apps only do one well. |
| **Linked reminders** | Let an assignment reminder auto-generate a "start studying" reminder a few days earlier, as a linked pair. | Encodes student workflow (prep → deadline) instead of one flat reminder. |
| **Voice memo reminders** | Record a 5-second voice note instead of typing when adding a reminder in a rush between classes. | Faster than typing when walking between classes. |
| **Weather-aware reminders** | If a reminder involves leaving campus/home (detected by keywords like "go to," "walk to"), show a small weather hint ("bring an umbrella") alongside the notification. | Small but genuinely useful touch no reminder app currently does. |

**Recommendation:** Don't build all of these — pick 1–2 that feel most "SuperNote" to you (Timetable Photo Scan + Deadline Countdown Widget are probably the highest-impact, most demo-able pair) and treat the rest as a backlog for later versions.
