Tại sao chọn SuperNote?

Kết hợp quản lý task truyền thống với AI và widget Android gốc, giúp bạn luôn cập nhật công việc mọi lúc mọi nơi.

🤖

AI Parsing Thông minh

Nhập nhanh 1+ task cùng lúc qua AI. Tự động nhận diện tiêu đề, ngày giờ, danh mục, nhắc nhở, tags và mô tả từ câu tự nhiên.

📌

Widget Android Gốc

3 kích cỡ widget: TaskList (4x3), QuickTask (1x1), Progress (4x1). Xem task trực tiếp trên màn hình chính.

📅

Calendar Tích hợp

Xem task theo ngày trên calendar. Nhanh chóng thấy task hôm nay, task đến hạn và lên kế hoạch trực quan.

🔔

Thông báo Thông minh

Nhắc nhở trước giờ, Quiet Hours tự động, nhắc lại task hết hạn, boot receiver sau khởi động lại máy.

🎨

Tùy biến Giao diện

Background ảnh/video tùy chọn, theme Cyber-Luxe Glassmorphism, overlay mờ trên mỗi card. Dark mode.

🔁

Đồng bộ Firebase

Đăng nhập Google, đồng bộ task realtime qua Cloud Firestore. Dữ liệu an toàn trên đám mây.

🌐

Đa ngôn ngữ

Hỗ trợ tiếng Việt và tiếng Anh (i18n). Tự động nhận diện ngôn ngữ thiết bị.

📈

Thống kê & Timeline

Biểu đồ tiến độ, timeline task trực quan, thống kê năng suất theo tuần/tháng.

🚀

Tự động Cập nhật

Kiểm tra version mới từ GitHub Releases mỗi lần mở app. Tải và cài đặt từ trong app.

📖 Hướng dẫn

Bắt đầu với SuperNote

Chỉ 4 bước đơn giản để bắt đầu quản lý task hiệu quả.

01

📥 Tải & Cài đặt

Tải APK từ GitHub Releases. Bấm Cài đặt trên thiết bị Android. Cho phép cài từ nguồn không xác định nếu được hỏi.

02

🔒 Đăng nhập Google

Mở app, bấm Sign in with Google. Dữ liệu sẽ được đồng bộ lên Cloud Firestore. An toàn và bảo mật.

03

📝 Tạo Task

Bấm nút "+" để thêm task. Gõ câu tự nhiên như "Họp team thứ 6 lúc 2h chiều" — AI sẽ tự động parse.

04

📌 Thêm Widget

Ấn giữ màn hình chính > Widgets > SuperNote. Chọn TaskList, QuickTask hoặc Progress Widget.
